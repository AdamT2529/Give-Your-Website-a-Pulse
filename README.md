# Give Your Website a Pulse
This is a very simple website created to introduce to nasa daily astronomy image site with their API. It fetches data from the API to create a title, photo/video, and description for what nasa posted depending on the day

Site: https://adamt2529.github.io/Give-Your-Website-a-Pulse/

# Features
-Fetches nasa’s astronomy picture of the day displaying  
-title 
=image
-and explanation updated automatically every day
